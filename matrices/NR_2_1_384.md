# Matrix: NR_2_1_384

## Basic Properties
- **Type**: 5G NR LDPC Shift Coefficient Matrix
- **Base**: Base Graph 2 (BG2)
- **Lifting size (Z)**: 384
- **Base matrix rows**: 42
- **Base matrix columns**: 52
- **File format**: Text file with shift coefficients

## Description
This file contains the shift coefficients used to construct the quasi-cyclic LDPC parity-check matrix for 5G NR.

## Shift Coefficient Semantics
Each entry in this matrix represents a Z × Z submatrix in the final parity-check matrix:

| Coefficient | Meaning |
|------------|---------|
| -1 | Z × Z all-zero matrix |
| ≥ 0 | Z × Z identity matrix with cyclic right shift |

## Matrix Construction Process
```
Shift matrix (42 × 52) with entries s ∈ {-1, 0, 1, ..., Z-1}
         ↓
For each entry s:
- If s = -1: Create Z × Z zero block
- If s ≥ 0: Create Z × Z identity shifted right by s positions
         ↓
Final H matrix: (42·Z) × (52·Z) = 16,128 × 19,968
         ↓
Quasi-cyclic LDPC code
```

## Generated Matrix Properties
From these shift coefficients, the final parity-check matrix has:
- **Dimensions**: 16,128 rows × 19,968 columns
- **Structure**: Quasi-cyclic (QC-LDPC)
- **Sparsity**: ~99.97%

## Loading in Code
```python
import numpy as np
import scipy.sparse as sp

# Read shift coefficients
shifts = np.loadtxt('NR_2_1_384.txt', dtype=int)

# Generate QC-LDPC matrix (pseudo-code)
Z = 384
m, n = shifts.shape  # 42 × 52
H = sp.lil_matrix((m*Z, n*Z))

for i in range(m):
    for j in range(n):
        if shifts[i,j] >= 0:
            # Add shifted identity matrix
            shift = shifts[i,j]
            for k in range(Z):
                H[i*Z + k, j*Z + (k + shift) % Z] = 1

H = H.tocsr()
```
