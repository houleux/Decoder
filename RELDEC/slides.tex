\begin{frame}
\frametitle{State Space [TO COMPLETE]}

\begin{itemize}
    
    \item The state space is factored into num-cluster sub-state spaces. 
    \item Each of these sub-state spaces represent the hard decoded bits of all variable nodes that are neighbors to a cluster
    
\end{itemize}

\end{frame}

%% ---------------------------------------------------------------------

\begin{frame}
\frametitle{Rewards and Transitions}

\begin{itemize}
    \item Reward: Fraction of correctly decoded bits
    \item Action: To schedule any cluster
    \item Transitions: Simulated using a dynamic layered belief propagation decoder
    
\end{itemize}

\end{frame}

%% ---------------------------------------------------------------------

\begin{frame}
\frametitle{Independence}

\begin{itemize}
    
    \item Scheduling a cluster, can also change the state for another cluster (due to shared variable nodes). Thus these sub-MDPs are not truly independent. However, the authors assume independence.
    \item For the sake of this paper, this assumption is not very relevant since most experiments are done with cluster size 1 or 2
    \item In previous work by the same authors, they have discussed a strategy to minimize these dependencies between clusters
\end{itemize}

\end{frame}
