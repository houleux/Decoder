## Matrix Construction
This matrix is generated from the shift coefficient matrix (`NR_2_1_384.txt`):

1. Base graph: 42 rows × 52 columns
2. Each base graph entry = one Z × Z submatrix
3. Shift coefficients specify cyclic shift amount:
   - -1 → All-zero Z × Z matrix
   - ≥ 0 → Z × Z identity matrix shifted right by that amount

Result: Quasi-cyclic structured LDPC code with efficient implementation.
